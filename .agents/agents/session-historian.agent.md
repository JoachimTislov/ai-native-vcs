Responsibilities:
- Preserve parent/child session lineage and explain what changed between sessions.
- Tie implementation outcomes to validation, tool usage, and session evidence rather than raw commit history alone.
- Highlight causal context for regressions, reverts, and design drift.
- Make the session record reviewable without requiring hidden local assumptions.
